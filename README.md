# VeriReturn

面向电商售后的**可验证事务型 Agent**。项目解决的核心问题是：让大模型负责理解客户表达，让业务系统负责金额、资格、权限、库存和状态变化；每次高风险动作都可以恢复、审计和复核。

## 项目贡献

- 构建 LangGraph 售后 Agent：支持意图识别、订单/商品/数量/取件时段槽位补全、多任务切换、长期记忆恢复，以及确认后执行。
- 设计受约束工具边界：Agent 不能直接写库；退款、换货、人工审核、预约取件均通过类型化 API、幂等键和状态机执行。
- 实现订单行级售后：支持多商品选择、部分退款、退款数量控制、金额分摊、库存预占、库存过期释放与换货履约异常。
- 落地可靠异步链路：基于 PostgreSQL Outbox/Inbox、租约、幂等和重试，处理取件、履约、退款提交及支付回调的重复、乱序与崩溃恢复。
- 实现支付与对账边界：退款完成仅由已验签支付渠道事实驱动；回调校验事件 ID、金额、币种、发生时间，并生成对账差异与运营事故。
- 建设人工审核闭环：策略版本化、审核工单、乐观锁、SLA 超时、受控附件上传、客户隔离和审计事件。
- 构建证据驱动知识问答：PostgreSQL `pgvector`、中文全文检索、版本化知识发布、检索引用与反馈闭环；RAG 不能决定业务事实。
- 提供可观测与生产化基础：Trace 下钻、离线评测、指标告警、OIDC/JWKS 适配、RBAC、Redis 限流、PII 脱敏、数据保留和备份恢复脚本。

## 技术栈

`Python` · `FastAPI` · `LangGraph` · `PostgreSQL` · `SQLAlchemy` · `Alembic` · `pgvector` · `Redis` · `React` · `TypeScript` · `Vite`

## 工程质量

- 73 个单元/API 测试通过，另有 PostgreSQL 并发与迁移集成测试。
- CI 自动执行 Python 测试、PostgreSQL migration upgrade/check 和前端生产构建。
- 本地演示页提供对话、受控工具调用、确认命令、任务记忆和履约事实的可视化。
